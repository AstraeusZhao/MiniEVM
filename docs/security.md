# Security Policy

Do not report issues that could affect execution correctness, state integrity, or resource
use in a public issue. Contact the maintainers through a private repository channel and
include the affected commit, preconditions, reproduction steps, impact, and a suggested
mitigation.

MiniEVM is a compact execution-engine project, not a production Ethereum or L2 client. This
scope does not reduce the importance of reports involving crashes, excessive resource use,
or incorrect state transitions.
