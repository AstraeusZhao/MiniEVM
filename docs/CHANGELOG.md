# Changelog

All notable changes to MiniEVM are documented here.

## 0.1.0 — Unreleased

- Initial execution engine with state transactions, stack VM, persistent storage, and basic control flow.
- Added gas accounting, bounded linear memory, tracing abstractions, and block environment values.
- Added public contribution, security, governance, and CI documentation.
- Hardened full-width arithmetic and transaction rollback/overflow handling.
